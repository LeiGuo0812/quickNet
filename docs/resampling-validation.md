# 重抽样、置换与失败处理核验

本核验覆盖横断面行 bootstrap、纵向参与者整簇 bootstrap、独立组 NCT 的统计量及多重校正、Mantel 节点置换，以及失败和未定义统计量的分母。此前配对 NCT、MTD 与 NetworkPower 的模拟记录分别保留在各自的验证文档，本轮未重复那些完整模拟。

运行 `Rscript tools/validate-resampling.R` 可复现本轮检查；也可分别运行 `parity`、`row`、`cluster`、`cluster_ols`、`nct_continuous`、`nct_binary`；OLS 部分依赖已生成的 CLPN 数据。输出默认保存到工作区的 `output/audit/resampling/`，包括源软件数值比较、逐数据集覆盖情况、原始数据和区间 RDS、失败原因与运行环境。模拟采用固定种子；完整运行需要数分钟。`tests/testthat/test-resampling-validation.R` 另外提供确定性的公式、边界和失败回归检查。

## 当前实现与核验标准

- 横断面边稳定性逐次抽取与原样本等量的观测行，有放回，重新调用原模型及原参数。边区间取有效估计的 2.5% 和 97.5% 分位数。失败样本不会被新抽样替换，选择率、均值和区间以有效估计为分母；请求、成功、失败、有效和未定义次数在表中分别记录。失败详情位于表的 `resampling` 属性；`Stability()` 还提供顶层 `$resampling` 入口。
- 自有 case-drop 表计算原始与删样后节点中心性向量的相关性，记录请求删除比例、实际删除比例、实际保留人数、有效及未定义相关次数。原始或重估中心性向量为常数时，相关性未定义，记为 NA；网络拟合本身可以完全有效。该表不是 CS 系数。
- EBICglasso 的附加 `bootnet` 结果和 CS 系数直接调用源包。`bootnet` 对失败拟合重新抽样的规则保留；包装层记录其警告和源软件实际报告的重试失败总次数，未报告的次数保持 NA，不推断为零。与自有固定请求次数的 bootstrap 结果应分别阅读。
- 纵向 bootstrap 有放回抽取独立参与者，保留该人的全部观测和时间顺序，为重复抽中的每个副本建立新 ID。至少需要两名参与者；这只是可计算边界，不能保证小簇数区间可靠。只有全部请求层均存在、维度和节点匹配、边有限，且源后端未确认失败，整次重复才有效。输出区间限于非对角边，不包含自回归系数。原因及计数位于结果及各层表的 `resampling` 属性。
- 源后端已报告不收敛或不可接受的模型会被排除；未提供收敛状态的后端记录为未知，不擅自认定为已收敛或失败。失败样本的条件分布可能不同于完整 bootstrap 分布；高失败率本身不能靠删除失败修复。
- NCT 保持源软件的独立组标签置换、含相等情况的 `(1 + 极端次数)/(1 + 置换次数)` p 值。全部请求边构成一个校正族；全部请求的“节点 × 中心性指标”构成另一个校正族。网络拟合错误中止测试，不悄悄缩小分母；若某中心性原统计量或任何置换统计量未定义，该比较 p 值为 NA，并记录 `centrality_validity`。二分类原始划分也必须满足条件置换所用的每组、每节点、每类别至少两条观测的限制。
- `netCor()` 保持 `ape::mantel.test()` 的统计量和三种备择的原 p 值规则。它同时置换第二个网络的节点行和列；其假设涉及节点标签可交换性，不是参与者重抽样或两个总体网络相等的检验。由于源方法只用一个三角，接口明确只接受对称无向网络。源方法允许两个节点；此时只有一条边，节点置换不改变统计量，p=1。

## 既有源软件的数值核对

使用实际安装的 bootnet 1.9.1、ape 5.8.1、glmnet 5.0（完整环境见运行记录），以及 NetworkComparisonTest 2.2.2 官方提交 `f05b102f2fa5c64da2f41e39052acbce18cff633`：

| 对照 | 核验对象 | 最大绝对差 |
|---|---|---:|
| bootnet | 39 个原始 bootstrap 数据集逐次用 quickNet 重估相关网络 | 2.22 × 10^-16 |
| bootstrap 分位数 | 上述同批源软件估计的独立 `stats::quantile` 区间 | 5.55 × 10^-17 |
| bootnet CS | 99 次 native case bootstrap，独立按源定义的相关阈值概率计算 | 0 |
| NCT | none、Holm、BH，以及默认 GGM / Ising 的不等 n 检查；全部全局/边/中心性 p 值及置换统计量 | 0 |
| ape | two.sided、greater、less，同种子节点置换 | 0 |

这验证的是实现与具体源软件输出的数值一致，不构成所有样本条件下的统计可靠性证明。自有 bootstrap 与 bootnet 的随机数消耗/失败重试规则不同，所以通过源软件保存的实际抽样数据逐次回放，避免把不同抽样序列误认为算法差异。

独立公式检查额外穷举 6 条观测分到两组各 3 条的全部 20 种划分，使用整数交叉积网络独立计算全局强度差、最大边差、全部边差、strength 和 expected influence 差。将观测划分与其他 19 种划分组成完整参照集，核对 none、Holm、Bonferroni、BH、BY、Hochberg、Hommel、FDR 八种校正。该检查验证统计量及校正族，并不把这样的小样本当作实际网络估计的建议样本量。

## 有限模拟设计

横断面为 3 个场景，每场景 120 个独立数据集、每数据集 99 次 bootstrap：60 人、3 节点、总体零相关；同样本下一个总体相关为 0.3；以及两条 0.15 部分相关边构成的弱链，使用 EBICglasso 默认 gamma 0.5。每场景分别检查预先指定的目标边和零边。

纵向为 12 与 80 名独立参与者，各 80 个数据集、每数据集 79 次整簇 bootstrap；2 节点、3 波，真实转移矩阵为 `[[0.3, 0], [0.25, 0.3]]`（行是结果、列是预测变量），正态独立创新，初始变量为独立标准正态。`PanelNet()` 使用原有 lasso/CV 方法，3 折，数据及 glmnet 标准化均关闭，检查真实交叉滞后 0.25 和反方向零效应。该场景有受试者内的时间依赖，但无额外随机截距；不能据此推断所有多层/不平稳模型的覆盖率。

每条边的覆盖率以外层数据集为独立单位，提供 Monte Carlo 标准误和精确二项 95% 区间。不同边不能当作独立重复来压低误差。99/79 次内层抽样意味着区间端点仍有明显有限模拟误差；结果描述这一有限预算程序，不代表无限 bootstrap 的极限表现。

| 场景 | 边真值 | 覆盖次数 | 覆盖率 | MCSE | 精确95%区间 |
|---|---:|---:|---:|---:|---:|
| 相关0.3，a→b | 0.3 | 114/120 | 95.0% | 1.99个百分点 | [89.4%, 98.1%] |
| 零相关，a→b | 0 | 115/120 | 95.8% | 1.82个百分点 | [90.5%, 98.6%] |
| 弱链 EBICglasso，a→b | 0.15 | 83/120 | 69.2% | 4.22个百分点 | [60.1%, 77.3%] |
| 相关0.3，a→c | 0 | 114/120 | 95.0% | 1.99个百分点 | [89.4%, 98.1%] |
| 零相关，a→c | 0 | 112/120 | 93.3% | 2.28个百分点 | [87.3%, 97.1%] |
| 弱链 EBICglasso，a→c | 0 | 120/120 | 100.0% | 0.00个百分点 | [97.0%, 100.0%] |
| CLPN，12人，a→b | 0.25 | 47/80 | 58.8% | 5.50个百分点 | [47.2%, 69.6%] |
| CLPN，80人，a→b | 0.25 | 38/80 | 47.5% | 5.58个百分点 | [36.2%, 59.0%] |
| CLPN，12人，b→a | 0 | 80/80 | 100.0% | 0.00个百分点 | [95.5%, 100.0%] |

上述主分析的 35,640 次横断面和 12,640 次 CLPN bootstrap 均无拟合失败。即使没有失败，弱 EBICglasso 和默认 CLPN 的真实非零边仍明显欠覆盖。不能据此“修正”分母或自动改变源软件正则化规则。

OLS 参考使用同一批 160 个面板数据集及相同的 79 次受试者抽样，以 `stats::lm.fit()` 拟合无正则的转移系数。脚本核验当前 PanelNet 的随机数消耗，再保存实际 `sampled_indices`；只在验证参考中使用 OLS，不增加公开模型或修改默认值。OLS 真交叉边的覆盖为 92.5% 和 95.0%，显著高于同数据/抽样下的 CLPN；结合源估计器数值一致性，这支持将此场景中的主要欠覆盖归因于 lasso/CV 缩减和百分位区间组合，而非把抽样机制一致性误当作普遍95%覆盖保证。该归因仍限于本模拟设计；OLS 零边覆盖也有有限样本和内层预算误差。

## 独立 NCT 的有限零假设筛查

额外预设两个同分布零假设场景，各100个独立数据集、99次置换：连续变量为3节点、总体相关0.25、两组n=40/80，使用默认GGM gamma=0.5；稀疏二分类为3个独立 Bernoulli(0.1) 节点、两组n=80/120，使用源 IsingFit gamma=0.25。二分类有1个原始划分未满足类别最小计数，明确拒绝并单列，因此有效分母为99；不把它算作未拒绝。其余调用没有拟合失败或未定义指标。

| 场景 | 检验 | 拒绝次数/有效次数 | 拒绝率 | MCSE | 精确95%区间 |
|---|---|---:|---:|---:|---:|
| 连续，不等n | 全局强度 | 5/100 | 5.00% | 2.18个百分点 | [1.64%, 11.28%] |
| 连续，不等n | Holm 边族 | 2/100 | 2.00% | 1.40个百分点 | [0.24%, 7.04%] |
| 连续，不等n | Holm strength 节点族 | 1/100 | 1.00% | 0.99个百分点 | [0.03%, 5.45%] |
| 连续，不等n | 最大边差 | 4/100 | 4.00% | 1.96个百分点 | [1.10%, 9.93%] |
| 稀疏二分类 | 全局强度 | 1/99 | 1.01% | 1.00个百分点 | [0.03%, 5.50%] |
| 稀疏二分类 | Holm 边族 | 0/99 | 0.00% | 0.00个百分点 | [0.00%, 3.66%] |
| 稀疏二分类 | Holm strength 节点族 | 0/99 | 0.00% | 0.00个百分点 | [0.00%, 3.66%] |
| 稀疏二分类 | 最大边差 | 1/99 | 1.01% | 1.00个百分点 | [0.03%, 5.50%] |

结果未显示所测强零假设下的明显反保守性；部分检验较保守。这仅是精度有限的筛查：例如连续全局强度拒绝率5%的区间仍宽至1.64%–11.28%。零次拒绝时插件MCSE为0不等于已确定真实错误率为0，须同时阅读精确区间。两场景均满足独立同分布的标签可交换假设，不能扩展到仅网络相同但均值/方差不同的总体。


固定稀疏二分类压力样本为 30 人、3 节点、每节点只有两个 1。199 次真实 Ising 重估中有 160 次失败，失败率 80.4%，Monte Carlo 标准误 2.81 个百分点，精确二项 95% 区间为 [74.2%, 85.7%]。39 次有效估计才是此表条件区间的分母；失败原因逐条保存在 `sparse-binary-failure-details.csv`，包含失去某类别和源估计器抛出的错误。该固定样本检查不是二分类区间总体覆盖率研究，也不证明此稀疏场景适合推断。

## 解释范围

百分位区间是估计不确定性的描述。正则化和模型选择可使真实非零边的区间欠覆盖，而零边可能过度覆盖；不能把“95% 区间”直接解读为已经校准的边显著性检验。簇数少、二分类样本稀疏、失败率高以及中心性向量无变异时尤其需要查看有效分母。区间核验不扩展为对所有 MGM、序数、psychonetrics 或 mlVAR 数据生成机制的覆盖保证。
